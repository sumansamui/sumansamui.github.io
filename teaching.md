## 📘 EC9036 — ASIC Design Using Verilog

**Course Level:** M.Tech  
**Department:** Electronics & Communication Engineering  
**Semester:** Even Semester  

### 🔍 Course Description
This course introduces the fundamentals of ASIC design, covering RTL modeling, Verilog HDL, synthesis flow, simulation, testbenches, and digital hardware implementation strategies. Students learn how complex logic is mapped to silicon through industry-standard methodologies.

### 📄 Syllabus / Course Content
👉 [Download EC9036 Course Content (PDF)](assets/EC9036_syllabus.pdf)

*(Upload your syllabus PDF to the `assets` folder and the link will work.)*

### 🍀 Lecture Modules
- **Module 1:** Introduction to ASIC Flow  
- **Module 2:** Verilog Basics — Syntax, Operators, Procedural Blocks  
- **Module 3:** Combinational Circuit Coding + Testbenches  
- **Module 4:** Sequential Logic, FSM Modeling, Pipelines  
- **Module 5:** Synthesis Flow & Constraints (DC Scripts)  
- **Module 6:** Simulation Strategies (Modelsim/Vivado)  
- **Module 7:** Verification Basics & Code Coverage  
- **Module 8:** RTL to GDS Overview  

### 🧪 Lab Components
- Verilog coding for combinational & sequential circuits  
- Writing testbenches and waveform analysis  
- Designing finite-state machines  
- Synthesis using Vivado/Design Compiler  
- Timing analysis  
- Mini ASIC design project

## 📘 ECC504 — Artificial Intelligence & Machine Learning

**Course Level:** UG  
**Department:** Electronics & Communication Engineering  
**Semester:** Even Semester  

### 🔍 Course Description
This course introduces fundamental and modern concepts in Artificial Intelligence and Machine Learning. It covers supervised/unsupervised learning, model evaluation, neural networks, optimization, and applications in real-world decision-making.

### 📄 Syllabus / Course Content  
👉 [Download ECC504 Course Content (PDF)](assets/ECC504_syllabus.pdf)

*(Upload your syllabus as `assets/ECC504_syllabus.pdf` in your repository.)*

### 🍀 Lecture Modules
- **Module 1:** Introduction to AI, intelligent agents, search  
- **Module 2:** Machine Learning basics, loss functions, generalization  
- **Module 3:** Supervised Learning – Regression, Classification  
- **Module 4:** Naive Bayes, KNN, Decision Trees, Random Forest  
- **Module 5:** SVM, Bias–Variance, Regularization  
- **Module 6:** Neural Networks, Backpropagation  
- **Module 7:** Deep Learning (CNN/RNN basics)  
- **Module 8:** Introduction to AI applications, ML pipelines  

### 🧪 Lab Components
- Python programming basics for ML  
- Data preprocessing, feature engineering  
- Training classical ML models  
- Neural network training using TensorFlow/PyTorch  
- Mini Projects (image/speech/data classification)
